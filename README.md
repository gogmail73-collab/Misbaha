# Misbaha

تطبيق سبحة إلكترونية عربي يعمل دون إنترنت بعد التثبيت.

## المميزات
- عداد يزيد مع كل ضغطة على زر «سبّح».
- تراجع عن آخر ضغطة وتصفير مع تأكيد.
- حفظ العدد باسم الذكر اختيارياً.
- سجل محفوظات محلي على الجهاز.

## الحصول على APK
يُبنى التطبيق تلقائياً عبر GitHub Actions عند التحديث على main.
افتح تبويب Actions، واختر تشغيل **Build Misbaha APK** إذا لم يبدأ تلقائياً.
بعد نجاح البناء، افتح التشغيل ونزّل Artifact باسم **Misbaha-APK**، ثم فك ملف ZIP لتجد app-debug.apk.

هذا إصدار Debug للتثبيت التجريبي على Android، وليس إصدار متجر Google Play.
